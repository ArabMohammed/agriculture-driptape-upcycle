# ReWeave — Circular Agriculture

A single-page static website for **ReWeave**, a project that upcycles end-of-life
drip irrigation tapes into durable woven agricultural mats for water conservation,
weed suppression, and erosion control.

## Structure

```
index.html        # the page
css/style.css     # styles
js/script.js      # mobile nav toggle + footer year
images/           # photos and diagrams
```

## Run locally

It's a static site — just open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```
